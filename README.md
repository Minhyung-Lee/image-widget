# Image widget

A small Windows desktop window for displaying an image. It stays on top, moves by dragging, and resizes from its lower-right corner while preserving the image's proportions.

The included `image.png` is synthetic placeholder artwork generated by `MakeDummy.cs`.

## Build and run

Requirements: Windows with .NET Framework 4.x and its built-in C# compiler. No package downloads, installer, administrator access, or startup registration are needed.

1. Download or clone this repository.
2. Run `build.cmd` from File Explorer or a command prompt.
3. Open `bin\ImageWidget.exe`.

The build script compiles `ImageWidget.cs` with `widget.manifest` and copies `image.png` beside the executable. It uses the compiler at `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`, falling back to the 32-bit Framework directory. You can pass an optional output folder: `build.cmd C:\path\to\output`.

## Controls

- Move: drag the image or **Drag to move** bar.
- Resize: drag the diagonal grip next to **Resize** at the lower-right corner.
- Change image: click **이미지 설정** at the lower left and choose a local image (PNG, JPEG, BMP, GIF, or TIFF). Unsupported or invalid files show a warning and keep the current image.
- Close: click **×** in the upper-right corner.

The window keeps a readable minimum size and fits within the display's working area. It opens without taking keyboard focus. Only one instance of this demo runs at a time.

Small images initially display at their native pixel size, centered when the controls need more space. Dragging the resize grip enables enlargement. Images are drawn directly from the decoded source pixels, with no intermediate resized copy. Enlarging a small source cannot add missing detail.

## Use another local image

Use **이미지 설정** to display a local image for the current session. Selected files are decoded into memory and are never copied into this repository or saved. Closing and reopening the widget returns to the default `bin\image.png`.

To change that local default, replace `bin\image.png` with your own PNG. `bin/` is ignored by Git. Images load from disk at runtime and are not embedded in the executable. There is no network or upload functionality.

## Recreate the placeholder

Run `make-dummy.cmd`. It compiles and runs `MakeDummy.cs`, which draws a simple landscape from geometric shapes using `System.Drawing`. The temporary generator is removed after it finishes. Run `build.cmd` again to copy the regenerated placeholder to `bin/`.

## Source files

- `ImageWidget.cs`: WinForms window, drag and resize behavior.
- `widget.manifest`: standard-user execution and DPI awareness.
- `build.cmd`: reproducible local compilation.
- `MakeDummy.cs`, `make-dummy.cmd`: placeholder generator.
- `image.png`: generic placeholder only.
